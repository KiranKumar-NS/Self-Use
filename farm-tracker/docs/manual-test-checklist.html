🧪 Farm Tracker — Manual Test Checklist

How to use this checklist

  • Follow the order. Later tests use data created by earlier tests (buyers → transactions → dues → sales…).
  • For each case: do the Steps in the app, confirm the Expected result on screen, do the Verify checks on other pages, then open the Direct storage check (Firestore) 🗄 and confirm the actual stored document — this catches counter/summary drift, the biggest risk in this app.
  • Direct storage check — how to open it: Firebase Console → your project → Firestore Database → pick the collection → open the document. Keep that tab open beside the app and refresh it after each action. The app keeps ~5-min in-memory caches, so a stale screen is not a bug — but a wrong document is. Every money action must move BOTH rollup docs: monthlySummaries/<YYYY-MM>-<segment> (e.g. 2026-07-goats) and yearlySummaries/<year>-<segment> (e.g. 2026-goats). Segment ids are goats / chickens / dragon.
  • Not stored (computed live): Dues, receivables/payables and Notifications have NO collection — their storage check points at the underlying transactions instead. Notification dismissals live in this browser's localStorage, not Firestore.
  • Menu names to know: loans live under sidebar item "Owe & Lent", schedules under "Reminders", user admin under Admin → "Users". On mobile the bottom bar shows Home / Txns / Loans / Stock / More.
  • Notifications compute once on app load — always RELOAD the app before checking the bell 🔔 for a new alert.
  • Tap ✓ for pass, ✗ for fail. Write what went wrong in the note box. Progress saves in this browser automatically.
  • When done (or when you find bugs), press Copy report and paste the result back to Claude to get fixes.
  • Before you start: use test data you are okay keeping, OR run the app against a clean DB (node scripts/clean-db.js seed). For role tests you need a second browser/incognito window and node firebase/set-custom-claims.js <uid> <role>.
  • Cases marked optional need extra setup (second user, waiting for dates) — skip if not practical.
